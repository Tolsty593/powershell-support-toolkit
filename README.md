# PowerShell Support Toolkit
 
A collection of PowerShell scripts designed to assist Support Engineers, Service Desk Analysts, and IT Operations teams with diagnostics, troubleshooting, reporting, and automation.
 
## Purpose
 
The goal of this repository is to reduce manual effort, improve troubleshooting efficiency, and support operational excellence through automation.
 
## Areas Covered
 
- System Diagnostics
- Windows Administration
- Software Inventory
- Event Log Collection
- Network Troubleshooting
- User Support Automation
- Operational Reporting
 
## Toolkit Contents
 
### Get-SystemHealth.ps1
Collects key information about the local machine.
 
### Get-InstalledSoftware.ps1
Generates an inventory of installed software.
 
### Export-EventLogs.ps1
Exports Windows Event Logs for analysis.
 
### Network-Diagnostics.ps1
Performs common network troubleshooting checks.
 
### User-Support-Checklist.md
Support troubleshooting workflow and best practices.
 
## Why Automation Matters
 
Support engineers often spend significant time gathering diagnostic information. Automation helps:
 
- Reduce investigation times
- Improve consistency
- Reduce manual effort
- Improve customer outcomes
